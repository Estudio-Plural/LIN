## Complementariedad con Otras Plataformas

| Aspecto | TikTok | Reddit | YouTube |
|---------|--------|--------|---------|
| **Formato** | Videos cortos | Threads texto | Videos largos |
| **Duración** | 15-60 seg | Conversación | 5-60 min |
| **Tono** | Aspiracional | Argumentativo | **Analítico** ✅ |
| **Volumen reciente** | Alto (40-50%) | Medio | Bajo (4-5%) |
| **Valor único** | Trends virales | Conversaciones | **Transcripciones verbales** ✅ |

YouTube aporta:
- **Análisis en profundidad** (vs clips cortos TikTok)
- **Transcripciones para procesamiento NLP** (contenido verbal completo)
- **Cobertura mainstream** (BBC, canales educativos)

## Recomendación Técnica

Para compensar bajo volumen reciente:
1. **Aumentar límite a 150-200 videos/keyword** (vs 50 actual)
2. **Activar transcripciones automáticas** para análisis de discurso
3. Priorizar keywords hispanas (`crisis de masculinidad`, `manosfera`) donde hay más volumen reciente
